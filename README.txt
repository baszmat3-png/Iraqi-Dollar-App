طريقة الحصول على APK:
1) أنشئ مستودع GitHub جديداً وارفع محتويات هذا المجلد (بما فيه .github).
2) (اختياري) الرابط مضبوط مسبقاً على https://iraqi-dollar-drjx.onrender.com؛ لتغييره أضف متغير APP_URL في Settings > Variables.
3) تبويب Actions > Build APK > Run workflow.
4) بعد دقيقتين ونصف: ادخل على التشغيل وحمّل app-apk (يحتوي ملف app-release.apk) ثبّته على الهاتف.
ملاحظة: التطبيق غلاف WebView يفتح موقعك المنشور، فالسيرفر يجب أن يبقى شغّالاً على Render.
